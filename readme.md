## Спецификация УВМ
### Загрузка константы
A        | B         | C
---------|-----------|-----------
Биты 0—5 | Биты 6—17 | Биты 18—21
43       | Константа | Адрес

Размер команды: 3 байт. Операнд: поле B. Результат: регистр по адресу, которым является поле C.

Тест (A=43, B=600, C=10):

0x2B, 0x96, 0x28

### Чтение значения из памяти
A        | B        | C
---------|----------|-----------
Биты 0—5 | Биты 6—9 | Биты 10—35
60       | Адрес    | Адрес

Размер команды: 5 байт. Операнд: значение в памяти по адресу, которым является поле C. Результат: регистр по адресу, которым является поле B.

Тест (A=60, B=2, C=139):

0xBC, 0x2C, 0x02, 0x00, 0x00

### Запись значения в память
A        | B        | C
---------|----------|-----------
Биты 0—5 | Биты 6—9 | Биты 10—13
19       | Адрес    | Адрес

Размер команды: 2 байт. Операнд: регистр по адресу, которым является поле B. Результат: значение в памяти по адресу, которым является регистр по адресу, которым является поле C.

Тест (A=19, B=11, C=2):

0xD3, 0x0A

### Бинарная операция: "=="
A        | B        | C          | D          | E
---------|----------|------------|------------|-----------
Биты 0—5 | Биты 6—9 | Биты 10—35 | Биты 36—39 | Биты 40—46
25       | Адрес    | Адрес      | Адрес      | Смещение

Размер команды: 6 байт. Первый операнд: значение в памяти по адресу, которым является поле C. Второй операнд: регистр по адресу, которым является поле D. Результат: значение в памяти по адресу, которым является сумма адреса (регистр по адресу, которым является поле B) и смещения (поле E).

Тест (A=25, B=11, C=607, D=0, E=9):

0xD9, 0x7E, 0x09, 0x00, 0x00, 0x09

## Спроектированный язык ассемблера

Каждая инструкция в YAML представлена как объект с ключом `op` (операция) и аргументами (например, `value`, `addr`, `reg_addr`, `offset`).

### Пример

```yaml
- op: load_const  # имя операции
  value: 600      # операнд (зависит от операции)
  dest_addr: 10   # операнд (зависит от операции)

- op: read_mem
  dest_addr: 2
  src_addr: 139

- op: write_mem
  src_reg_addr: 11
  dest_mem_reg_addr: 2

- op: bin_eq
  result_base_reg_addr: 11
  left_mem_addr: 607
  right_reg_addr: 0
  offset: 9
```

### Поддерживаемые операции

#### 1) `load_const` — загрузить константу в регистр по адресу

**Семантика:** упаковка константы в регистр, адрес регистра задаётся полем `dest_addr`.

**Поля YAML:**
- `op: load_const`
- `value` — целочисленное значение (поле B в спецификации)
- `dest_addr` — целое (поле C)

**Размер команды:** 3 байта.

**Пример (тест из спецификации):**

```yaml
- op: load_const
  value: 600
  dest_addr: 10
```

Байты команды (ожидаемые): `0x2B, 0x96, 0x28`.

---

#### 2) `read_mem` — прочитать значение из памяти и поместить в регистр

**Семантика:** читается значение из памяти по адресу `src_addr`, результат записывается в регистр по адресу `dest_addr`.

**Поля YAML:**
- `op: read_mem`
- `dest_addr` — адрес регистра, куда помещаем значение (поле B)
- `src_addr` — адрес памяти, откуда читаем (поле C)

**Размер команды:** 5 байт.

**Пример (тест):**

```yaml
- op: read_mem
  dest_addr: 2
  src_addr: 139
```

Байты команды (ожидаемые): `0xBC, 0x2C, 0x02, 0x00, 0x00`.

---

#### 3) `write_mem` — записать значение из регистра в память (через регистр-адрес)

**Семантика:** источник — регистр по адресу `src_reg_addr`; место записи — ячейка памяти по адресу, который хранится в регистре по адресу `dest_mem_reg_addr`.

**Поля YAML:**
- `op: write_mem`
- `src_reg_addr` — адрес регистра-источника (поле B)
- `dest_mem_reg_addr` — адрес регистра, содержащего целевой адрес памяти (поле C)

**Размер команды:** 2 байта.

**Пример (тест):**

```yaml
- op: write_mem
  src_reg_addr: 11
  dest_mem_reg_addr: 2
```

Байты команды (ожидаемые): `0xD3, 0x0A`.

---

#### 4) `bin_eq` — бинарная операция сравнения "==" с особенностями адресации

**Семантика:**
- Первый операнд — значение в памяти по адресу `left_mem_addr` (поле C).
- Второй операнд — регистр по адресу `right_reg_addr` (поле D).
- Результат записывается в память по адресу, полученному как сумма: (значение регистра по адресу `result_base_reg_addr` (поле B)) + `offset` (поле E). То есть значение записывается в память по вычисленному адресу.

**Поля YAML:**
- `op: bin_eq`
- `result_base_reg_addr` — адрес регистра (поле B)
- `left_mem_addr` — адрес памяти первого операнда (поле C)
- `right_reg_addr` — адрес регистра второго операнда (поле D)
- `offset` — целочисленное смещение (поле E)

**Размер команды:** 6 байт.

**Пример (тест):**

```yaml
- op: bin_eq
  result_base_reg_addr: 11
  left_mem_addr: 607
  right_reg_addr: 0
  offset: 9
```

Байты команды (ожидаемые): `0xD9, 0x7E, 0x09, 0x00, 0x00, 0x09`.

## Этапы работы

### Этап 1
* Спроектирован человекочитаемый язык ассемблера, используя формат YAML с поддержкой всех команд спецификации УВМ.
* Реализован транслятор, который язык ассемблера преобразует во внутреннее представление (список объектов класса Operation)

### Этап 2
* Реализован транслятор из промежуточного в машинное представление с записью результата ассемблирования в двоичный выходной файл.

### Этап 3
* Реализован интерпретатор с основным циклом выполнения команд.
* Создана объединенная модель памяти УВМ и реализованы операции работы с памятью (загрузка констант, чтение/запись).
* Реализован вывод дампа памяти в формате JSON и протестирована работа на программе копирования массива.

### Этап 4
* Реализована поддержка интерпретатором операции сравнения на равенство ("==").

## Сборка проекта
1. Установите Python версии 3.12
2. Перейдите в папку проекта
3. Установите зависимости
    ```
    python -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt
    ```
4. Сборка: `build.bat`
5. Готово: `dist\assembly.exe` `dist\interpret.exe`
